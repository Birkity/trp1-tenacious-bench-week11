# Ablation Results — Act IV

Generated by `scripts/analysis/run_ablation.py` after SimPO training.

## Files

| File | Description |
|------|-------------|
| `ablation_results.json` | Per-task verdicts, accuracy metrics, dimension error counts for dev and held_out partitions |
| `held_out_traces.jsonl` | Raw model output for each task — base model and trained judge responses |

## How to regenerate

```bash
# Dev partition (after training)
python scripts/analysis/run_ablation.py \
    --adapter-path tenacious_judge_adapter \
    --partition dev

# Held-out partition (final graded run)
python scripts/analysis/run_ablation.py \
    --adapter-path tenacious_judge_adapter \
    --partition held_out
```

Copy `ablation_results.json` and `held_out_traces.jsonl` from Colab output
(`/content/ablations/`) into this directory.
